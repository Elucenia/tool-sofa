### قلبي وعائي (جرعات mcg/kg/min لمدة ≥ ١ h)

`cv`

- `0` — متوسّط الضغط الشرياني ≥ ٧٠ mmHg، دون قابض وعائي
- `1` — متوسّط الضغط الشرياني \< ٧٠ mmHg
- `2` — دوبامين ≤ ٥ أو دوبوتامين (أيّ جرعة)
- `3` — دوبامين \> ٥، أدرينالين ≤ ٠٫١ أو نورأدرينالين ≤ ٠٫١
- `4` — دوبامين \> ١٥، أدرينالين \> ٠٫١ أو نورأدرينالين \> ٠٫١

## إصدار الطريقة

SOFA/Vincent 1996: 6 أجهزة 0–4، مجموع 0–24؛ العتبات الكلاسيكية؛ لا يشمل SOFA 2

## المعادلة الموثقة

لكل جهاز من 0 إلى 4 نقاط؛ المجموع من 0 إلى 24.

التنفّس (PaO₂/FiO₂): ≥ 400 = 0; \< 400 = 1; \< 300 = 2; \< 200 مع دعم تهوية = 3; \< 100 مع دعم = 4.

التخثّر (الصفائح ×10³/µL): ≥ 150 = 0; \< 150 = 1; \< 100 = 2; \< 50 = 3; \< 20 = 4.

الكبد (البيليروبين, mg/dL): \< 1.2 = 0; 1.2–1.9 = 1; 2.0–5.9 = 2; 6.0–11.9 = 3; ≥ 12 = 4.

القلب والدورة الدموية (جرعات الأدوية الفعالة وعائيًا بوحدة µg/kg/min، معطاة لمدة 1 ساعة على الأقل): متوسّط الضغط الشرياني ≥ 70 = 0; متوسّط الضغط الشرياني \< 70 = 1; الدوبامين ≤ 5 أو الدوبوتامين = 2; الدوبامين \> 5, الأدرينالين أو النورأدرينالين ≤ 0.1 = 3; الدوبامين \> 15, الأدرينالين أو النورأدرينالين \> 0.1 = 4.

الجهاز العصبي (Glasgow): 15 = 0; 13–14 = 1; 10–12 = 2; 6–9 = 3; \< 6 = 4.

الكلى (الكرياتينين, mg/dL, أو إدرار البول): \< 1.2 = 0; 1.2–1.9 = 1; 2.0–3.4 = 2; 3.5–4.9 أو إدرار البول \< 500 mL/يوم = 3; ≥ 5.0 أو إدرار البول \< 200 mL/يوم = 4.

## الحدود والفئة السكانية

يصف SOFA الكلاسيكي خلل وظائف الأعضاء لدى البالغين المصابين بأمراض حرجة؛ سجّل وقت التقييم ووظائف الأعضاء السابقة. في تعريف Sepsis-3 لعام ٢٠١٦، يجب أن تكون الزيادة الحادة بمقدار ٢ نقطة على الأقل ناجمة عن العدوى؛ ولا يجوز افتراض أن القيمة الأساسية صفر إلا عند عدم وجود خلل سابق معروف في وظائف الأعضاء. لا يشخّص المجموع وحده العدوى ولا يعطي احتمالًا فرديًا للوفاة. لا تعمّم التصنيف الكلاسيكي على الأطفال. تُعبّر جرعات الأدوية الفعّالة وعائيًا بوحدة µg/kg/min وتُعطى لمدة ١ ساعة على الأقل؛ ويشير إدرار البول إلى ٢٤ ساعة. يورد الجدول ١ من Sepsis-3 (٢٠١٦)، المقتبس من Vincent 1996، البيليروبين \> ١٢٫٠ mg/dL والكرياتينين \> ٥٫٠ mg/dL والدوبامين \< ٥ أو ٥٫١–١٥ µg/kg/min. لم يُحصل على جدول عام ١٩٩٦ الكامل في هذه المراجعة. لم يُحسم اختلاف هذه الحدود أو الفجوات بينها؛ واستخدم الفحص العددي قيمًا واضحة فقط ونقاطًا قلبية وعائية مختارة مسبقًا.
